=== ONZE2LÉGENDE — TES PHOTOS DE MAILLOTS ===

Dépose ici tes photos de maillots (dont tu as les droits : fournisseur,
dropshipper, ou tes propres clichés). Elles remplaceront automatiquement
les maillots dessinés sur le site. Si une photo manque, le maillot dessiné
reste affiché — aucun risque de "case vide".

------------------------------------------------------------
NOMS DE FICHIERS EXACTS À UTILISER (dans ce dossier) :
------------------------------------------------------------
  france-domicile.jpg     -> France domicile (AVANT)
  france-exterieur.jpg    -> France extérieur (AVANT)
  bresil.jpg              -> Brésil (AVANT)
  argentine.jpg           -> Argentine (AVANT)
  espagne.jpg             -> Espagne (AVANT)
  portugal.jpg            -> Portugal (AVANT)
  maroc.jpg               -> Maroc (AVANT)
  allemagne.jpg           -> Allemagne (AVANT)
  angleterre.jpg          -> Angleterre (AVANT)
  italie.jpg              -> Italie (AVANT)

PHOTOS DE DOS (face arrière, affichées sur la fiche produit) :
ajoute "-dos" avant l'extension. Exemples :
  france-domicile-dos.jpg, bresil-dos.jpg, argentine-dos.jpg, etc.
La carte de la boutique montre l'AVANT ; la fiche produit montre
AVANT + ARRIÈRE (clic sur les vignettes). Si une photo de dos manque,
le maillot dessiné (dos) s'affiche à la place.

Et pour la grande image d'accueil (hero), à placer dans le dossier PARENT
onze2legende/assets/ (pas ici) :
  hero-france.jpg         -> Maillot France stylé du haut de page

------------------------------------------------------------
CONSEILS PHOTO :
------------------------------------------------------------
- Format carré (1:1) idéalement, ex. 800x800 px ou 1000x1000 px.
- Fond uni sombre OU PNG transparent = rendu le plus propre sur le site.
- .jpg de préférence (sinon renomme ton .png/.webp en .jpg ne suffit pas :
  garde la vraie extension .jpg, ou demande-moi d'activer .png).
- Les cartes affichent la photo en plein cadre (recadrage centré) ;
  l'accueil et la fenêtre "choisir ma taille" l'affichent en entier.

Une fois les fichiers déposés sur GitHub dans ce dossier, le site les
prend en compte automatiquement au prochain déploiement (~2 min).
